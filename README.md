**# Rule-Based Chatbot

## Project Overview

This project is a simple Rule-Based Chatbot developed using Python as part of Task 1 of The Tech Alpha Consultancy Services Artificial Intelligence Internship.

The chatbot can take user input, match it with predefined keywords or patterns, and provide relevant responses. It also gives a default response when it does not recognize the user's query.

## Objective

The objective of this project is to create a simple chatbot that can answer predefined questions and hold a basic conversation.

## Technologies Used

- Python
- String Matching
- Conditional Statements
- Functions
- Dictionary

## Features

- Takes input from the user
- Matches predefined questions and keywords
- Provides relevant responses
- Handles unrecognized queries
- Allows basic conversation
- Exits when the user types "bye"
## How to Run

1. Download the `chatbot.py` file.
2. Open it in a Python-supported IDE or Google Colab.
3. Run the program.
4. Enter your questions in the chatbot.
5. Type `bye` to exit.

## Example

You: Hello  
Bot: Hello! How can I help you?

You: What is your name?  
Bot: I am a simple Rule-Based Chatbot.

You: Bye  
Bot: Goodbye! Have a nice day.

## Conclusion

This project demonstrates the basic working of a Rule-Based Chatbot using Python. It uses predefined responses, string matching, conditional statements, functions, and a dictionary to provide basic conversational interaction.vvvvvvvvvvv**
